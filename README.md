# ☕ 9's Cafe — Coffee Landing Page

A modern, responsive coffee café landing page built with **HTML, CSS, and Vanilla JavaScript**.  
The website focuses on a clean café experience with interactive UI components, responsive design, and a warm coffee-inspired visual theme.

## 📌 About The Project

**9's Cafe** is a modern coffee landing page designed to showcase a small-batch coffee brand.

The website includes information about coffee roasts, the café story, customer reviews, FAQs, and contact/newsletter interactions.

The project is completely frontend-based and uses **Vanilla JavaScript without external JavaScript dependencies**.

## ✨ Features

- 📱 Fully responsive design
- 🌙 Dark / Light mode
- 📌 Sticky navigation header
- 📱 Mobile navigation menu
- 🔄 Smooth scrolling
- 👀 Scroll reveal animations
- 🔝 Back-to-top button
- ⭐ Active navigation link based on scroll position
- ❓ Interactive FAQ accordion
- 📩 Newsletter subscription popup
- ✉️ Contact form validation
- 🔔 Toast notifications
- 💾 Theme preference stored using Local Storage
- ♿ Accessibility-friendly focus states
- 🎨 Modern coffee-inspired UI

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic elements
- **CSS3** — Styling, responsive layouts, animations and themes
- **JavaScript (Vanilla JS)** — Interactivity and form validation
- **LocalStorage** — Saving user theme and popup preferences
- **Intersection Observer API** — Scroll reveal and active navigation
- **SVG** — Icons and custom illustrations
